## 典型工作流

### 上传视频自动配乐

```text
上传视频 -> AI 分析画面节奏和情绪 -> 生成纯器乐 BGM -> 下载 BGM / 导出混音视频 / 导入剪映 Beta
```

适合短视频、Vlog、产品展示、游戏预告片、播客切片和广告素材。

### 文案生成配音和字幕

```text
输入短文或长文 -> 选择音色和模型档位 -> 生成自然语音 -> 下载音频 / 下载字幕 / 导入剪映 Beta
```

适合口播、课程、有声内容、小说章节和旁白。

### 中文描述生成音效和音乐

```text
输入声音描述 -> AI 生成音效或音乐 -> 试听 -> 下载或进入在线编辑器二次处理
```

适合游戏音效、短视频转场、环境氛围、UI 提示音和背景音乐。

## 重要边界

- 「导入剪映 Beta」不是剪映官方接口，不会自动打开剪映，不会覆盖用户已有草稿。
- 导入剪映需要用户手动选择并授权剪映草稿箱目录。
- 视频配乐默认主推纯器乐 BGM，不默认生成带人声歌曲。
- AI 配音当前公开入口为短文配音、长文配音和语音播客，不对外宣传已关闭的音色工坊或声音复刻入口。
- 上传视频原文件优先保留在浏览器本地，不作为长期平台素材保存。

## FAQ

**爱声音坊 (AiSounds) 是什么？**

爱声音坊是一个 AI 音频创作平台，支持 AI 视频配乐、AI 配音、AI 音效、AI 音乐、字幕输出、导入剪映 Beta、在线编辑和素材库。

**上传视频可以自动生成背景音乐吗？**

可以。上传 MP4 或 MOV 视频后，系统会分析画面场景、情绪和节奏，生成匹配的纯器乐 BGM，并支持下载 BGM 或导出混音视频。

**AI 配音支持哪些模式？**

当前公开入口包括短文配音、长文配音和语音播客。短文适合口播和旁白，长文适合课程稿和有声内容，语音播客适合把文章、网页、文件或主题整理成双人对谈音频。

**能生成字幕吗？**

可以。视频配乐和 AI 配音结果可按需生成字幕，支持 SRT、VTT、JSON 等格式，便于导入剪映、Premiere、CapCut 等剪辑软件。

**导入剪映 Beta 是官方接口吗？**

不是。它是 AiSounds 的网页端草稿生成能力：用户授权剪映草稿箱目录后，系统创建新草稿。它不会自动打开剪映，也不会覆盖已有草稿。

**可以生成音效和音乐吗？**

可以。AI 音效支持中文描述生成 1-30 秒音效；AI 音乐支持文本生成、音频改编和局部重绘。

**生成内容可以商用吗？**

可以用于短视频、游戏、播客、广告等商业项目，但不可二次分发、转售、打包出售或上传到其他素材平台。

**免费额度够用吗？**

注册送 200 积分，每日签到 +10 积分，足够体验核心功能。
