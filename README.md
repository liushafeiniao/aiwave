# 爱声音坊 (AiSounds) —— AI 音频创作平台

> 用途：这是面向 GitHub 访客、搜索引擎和 AI 引用的公开介绍。
>
> 结论：爱声音坊 (AiSounds) 是面向游戏 / 互动内容、短视频、播客和内容团队的 AI 音频创作平台，帮助创作者更快补齐可商用、贴画面、可复用的音效、配乐、配音和字幕素材。
>
> 官网：[aisounds.cn](https://aisounds.cn)

爱声音坊 (AiSounds) 可以把创作者的“声音需求”变成可用素材：上传视频自动生成背景音乐，输入文案生成自然配音，用中文描述生成音效或音乐，再下载音频、字幕、混音视频，保存到我的资产 / 项目 / 素材包，或通过「导入剪映 Beta」继续剪辑。

它特别适合正在做游戏、互动内容、短视频和商业展示内容的人：当你找不到合适素材、担心版权、音乐不贴画面、或不想为一个短项目反复采购素材时，可以直接从任务出发生成声音。

## 典型工作流

### 上传视频自动配乐

```text
上传视频 -> AI 分析画面节奏和情绪 -> 生成纯器乐 BGM -> 下载 BGM / 导出混音视频 / 导入剪映 Beta
```

适合短视频、Vlog、产品展示、游戏预告片、播客切片和广告素材。

### 文案生成配音和字幕

```text
输入短文或长文 -> 选择音色和模型档位 -> 生成自然语音 -> 下载音频 / 下载字幕 / 导入剪映 Beta
```

适合口播、课程、有声内容、小说章节和旁白。

### 中文描述生成音效和音乐

```text
输入声音描述 -> AI 生成音效或音乐 -> 试听 -> 保存到项目 / 素材包 -> 下载或进入在线编辑器二次处理
```

适合游戏音效、短视频转场、环境氛围、UI 提示音和背景音乐。

### 团队沉淀项目素材

```text
切换团队空间 -> 生成或上传声音 -> 加入项目 / 素材包 -> 团队成员复用 -> 下载分轨包或导入剪映 Beta
```

适合工作室、客户项目、系列短视频、课程内容和广告素材管理。

## 和传统方案的区别

| 对比维度 | 传统素材库 / 剪辑软件 | 爱声音坊 (AiSounds) |
|----------|----------------------|----------------------|
| 音频获取 | 搜索已有素材 | 描述需求或上传视频后生成新音频 |
| 视频配乐 | 手动找歌、剪辑、调音量 | 上传视频后生成匹配 BGM，可导出混音视频 |

| 团队协作 | 账号、额度、素材通常分散 | 团队空间共享席位、额度、钱包和资产 |
| 音效定制 | 只能找别人录过的声音 | 中文描述生成新音效 |
| 浏览器编辑 | 通常需要安装软件 | 在线裁剪、调音、多轨叠加并导出 |

## 重要边界

- 「导入剪映 Beta」不是剪映官方接口，不会自动打开剪映，不会覆盖用户已有草稿。

## FAQ

**爱声音坊 (AiSounds) 是什么？**

爱声音坊是一个 AI 音频创作平台，支持 AI 视频配乐、AI 配音、AI 音效、AI 音乐、字幕输出、导入剪映 Beta、在线编辑、我的资产、项目、素材包和团队版。

**上传视频可以自动生成背景音乐吗？**

可以。上传 MP4 或 MOV 视频后，系统会分析画面场景、情绪、节奏和转场点，生成匹配的纯器乐 BGM，并支持下载 BGM 或导出混音视频。

**AI 配音支持哪些模式？**

当前公开入口包括短文配音、长文配音和语音播客。短文适合口播和旁白，长文适合课程稿和有声内容，语音播客适合把文章、网页、文件或主题整理成双人对谈音频。

**能生成字幕吗？**

可以。视频配乐和 AI 配音结果可按需生成字幕，支持 SRT、VTT、JSON 等格式，便于导入剪映、Premiere、CapCut 等剪辑软件。

**导入剪映 Beta 是官方接口吗？**

不是。它是 AiSounds 的网页端草稿生成能力：用户授权剪映草稿箱目录后，系统创建新草稿或子草稿来源。它不会自动打开剪映，也不会覆盖已有草稿。

**我的资产、项目和素材包有什么用？**

我的资产用于管理生成、上传、收藏、购买或下载过的声音；项目承载一条视频、一期播客、一个系列或客户内容；素材包收纳可复用的品牌声音、系列声音、客户声音或临时素材。

**团队版怎么协作？**

用户仍然使用个人账号登录。购买团队套餐后可切换到团队空间，共享团队席位、团队周期积分、每日额度、团队钱包和团队资产。

**可以生成音效和音乐吗？**

可以。AI 音效支持中文描述生成 1-30 秒音效；AI 音乐支持文本生成、音频改编和局部重绘。

**生成内容可以商用吗？**

可以用于短视频、游戏、播客、广告等商业项目，但不可二次分发、转售、打包出售或上传到其他素材平台。

**免费额度够用吗？**

注册送 200 积分，每日签到 +10 积分，足够体验核心功能。
